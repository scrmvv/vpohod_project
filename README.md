# В Поход! — цифровой прототип

Это аккуратная новая версия прототипа: стили и логика вынесены из HTML в отдельные файлы.

## Структура

```text
index.html              основная игра
rules.html              краткие правила
styles/main.css         стили
js/data.js              роли, местности, погода, предметы
js/game.js              игровая логика и состояние
js/ui.js                отрисовка интерфейса и обработчики
assets/roles            фигурки ролей из лукбука
assets/markers          База, Промежуточная цель, Главная цель
assets/tiles            изображения местности из лукбука
assets/artifacts        карточки предметов из лукбука
```

## Что уже учтено

- На старте закрыты все карточки местности, кроме Базы и целей маршрута.
- Карточки открываются с flip-анимацией.
- Горы доступны только при выпавшей 6.
- Водоём доступен без плавсредства, но стоит 2 очка движения; с плавсредством — 1.
- На экране выбора ролей видно, какой игрок получает какую роль.
- Эмодзи не используются; роли, цели, местность и предметы взяты из лукбука.
- Код разделён на HTML, CSS и JS.
- Есть сохранение партии в localStorage.
- Есть финал со звёздами и текстом истории похода.

## Как запустить

Откройте `index.html` в браузере. Для стабильной проверки лучше запускать через локальный сервер:

```bash
python3 -m http.server 8000
```

Затем открыть в браузере:

```text
http://localhost:8000
```
